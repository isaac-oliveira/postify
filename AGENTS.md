# Instruções de desenvolvimento do Postify

## Ferramentas obrigatórias

- Use o Context7 sempre que estiver disponível para documentação atual e uso de APIs de bibliotecas, frameworks, SDKs, APIs e ferramentas de linha de comando.
- Use o Serena sempre que estiver disponível para navegação do codebase, símbolos, referências e edição semântica.
- Use o Graphify sempre que estiver disponível para entender dependências, arquitetura e relacionamentos do codebase.
- Prefira Context7, Serena e Graphify à busca manual quando eles responderem diretamente à tarefa.
- Se uma ferramenta necessária não estiver disponível, declare essa limitação e prossiga com a menor alternativa segura.

## Git

- Mantenha os commits atômicos: uma mudança lógica por commit.
- Use títulos curtos de Conventional Commit em inglês, sem descrições, metadados de coautoria ou declarações de autoria.
- Siga o roteiro Git do projeto para branches, pull requests, checks e operações de merge ou finalização.

## Estilo

- Seja conciso e siga as convenções existentes do projeto.
- Evite comentários, documentação, abstrações ou arquivos desnecessários.

## Clareza do código

- Não adicione comentários para explicar o código.
- Quando um comentário parecer necessário, melhore os nomes, a estrutura ou a simplicidade até que o código fique claro sem ele.
